# 🏗️ Steel Weight Calculator Pro

A free, fast, mobile-friendly web calculator for estimating the weight of steel sections — **MS Sheet, Plate, Angle, Round Bar, Square Bar, Pipe, Square Tube, Channel (ISMC) and I-Beam (ISMB)**.

🔗 **Live Demo:** [vijay-mena07.github.io/Steel-Weight-Calculator](https://vijay-mena07.github.io/Steel-Weight-Calculator/)

## ✨ Features

- 🧮 **8 section calculators** — plate, angle, round bar, square bar, pipe, tube, channel, beam
- 🎨 **7 materials** — MS, carbon steel, SS 304, aluminium, copper, brass, cast iron
- 📏 **Metric & Imperial** — mm/kg/MT or inch/lbs
- 📚 **Standard sizes preloaded** — ISMC, ISMB and common angle profiles
- 💾 **Save calculations** — last 20 stored in browser localStorage
- 📄 **PDF export** — one-click professional report via jsPDF
- 📱 **Fully responsive** — works on any screen
- 🔒 **100% client-side** — no server, no tracking of your inputs
