# 🏗️ Steel Weight Calculator Pro

A fast, accurate, and mobile-friendly web calculator for estimating the weight of steel sections — **MS Sheets, Plates, Angles, Round Bars, Square Bars, Pipes, Square Tubes, Channels (ISMC), and I-Beams (ISMB)**.

Built with **pure HTML, CSS, and vanilla JavaScript** — no build step, no framework, no dependencies (except optional jsPDF for PDF export).

## ✨ Features

- 🧮 **9 Shape Calculators** — Sheet/Plate, Angle, Round Bar, Square Bar, Round Pipe, Square/Rect Tube, Channel (ISMC), I-Beam (ISMB)
- 🎨 **8 Material Densities** — Mild Steel, Carbon Steel, SS 304, Aluminum, Copper, Brass, Cast Iron
- 📏 **Dual Unit System** — Metric (mm / kg / MT) and Imperial (inch / lbs / tons)
- 📚 **Preloaded Standard Sizes** — Common ISMC and ISMB profiles + popular angle sizes
- 💾 **Save Calculations** — Stores last 20 calculations in browser (localStorage)
- 📄 **PDF Export** — Download any calculation as a clean PDF report
- 📱 **Fully Responsive** — Works smoothly on mobile, tablet, and desktop
- 🚀 **Zero Dependencies for Core** — Just one HTML file works offline
- 🎯 **Accurate Formulas** — Based on standard steel density (7850 kg/m³) and cross-sectional geometry
